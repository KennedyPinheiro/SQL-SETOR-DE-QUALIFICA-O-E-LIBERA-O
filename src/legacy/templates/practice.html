AJUDA DA PRÁTICA

Use este ambiente para explorar dados e praticar SQL sem turnos, visitantes ou pontuação.

CARREGAR UM BANCO

Importe arquivos CSV ou TSV com cabeçalho, ou JSON com registros. Cada arquivo vira um agrupamento no explorador; arquivos JSON podem conter várias tabelas. Os dados importados existem nesta sessão e são descartados ao recarregar ou restaurar o banco.

EXPLORAR E CONSULTAR

Abra os acordeões em ordem: banco, tabela e coluna. “Consultar tabela” prepara um SELECT *; clicar em uma coluna prepara um SELECT daquela coluna. Edite o SQL e execute com o botão ou Ctrl + Enter.

EDITOR E RESULTADOS

O terminal usa o dialeto AlaSQL no navegador. Scripts .sql são carregados no editor para você revisar antes de executar. Arraste a divisória entre editor e resultados para ajustar o espaço. Oculte ou reabra os resultados pelo botão no cabeçalho do editor; ao executar uma consulta, os resultados voltam ao tamanho anterior.

HISTÓRICO

As instruções SQL executadas ficam no histórico local do navegador. Clique em uma entrada para carregá-la no editor. Use “Limpar” para apagar o histórico.
